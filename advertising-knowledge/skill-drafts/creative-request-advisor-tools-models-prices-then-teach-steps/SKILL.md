# Creative request advisor - recommend first, then teach

Built 21 Nov 2026. This skill owns only the ORDER of the answer for any creative request. Facts, prices and craft live in the hubs it routes to.

## Output rules for Moshe (hard)
- Answer in Hebrew, every message. Hebrew and English never on the same line: every English name, model, price label, path or link on its own line or in a code block.
- Never invent facts, prices, specs or rights; unverified -> say so.
- Never buy, start a trial, or press buy / upgrade / subscribe / publish / generate without stating in writing what and how much, and getting his explicit yes.
- Paid tools are never ruled out in advance: present them with cost, pros, cons, free alternative and a recommendation, and act only after his explicit approval.
- Never tell him "see section X": paste the text he needs.
- Do not end a reply with a question or an offer.
- Teach: define a new term once, the why in one sentence, numbered steps. He learns by doing.

## Step 0 - what is being made (silent, at most 2 questions if truly unclear)
Deliverable, where it will be shown, length / size, language, client or personal, deadline, budget ceiling. Client work or an ad -> commercial rights are mandatory in Step 2.

## Step 2 - the recommendation card (always before any how-to)
Re-check live before any number: run the owning price skill's live re-check (for video and image: `ai-video-tools-and-prices` Step 0; Higgsfield: the free estimate tools; sound: `suno-and-ai-sound-hub` cost line). A price older than 14 days is shown with its date and the words "not re-checked".

|---|---|---|---|---|---|---|---|
| Cheapest | | | | | | | |
| Most expensive | | | | | | | |
| Best quality | | | | | | | |
| Best value | | | | | | | |

Then: what he already has connected (from `ai-connectors-map`), the one recommendation and the reason in one sentence, and what it will cost for THIS job (units x live price x expected tries, buffer source stated).
Rules: "best quality" needs a dated source; "best value" shows its arithmetic and is labelled as reasoning; commercial rights UNKNOWN = not cleared for client work.
Stop here. Wait for his choice.

## Step 3 - after he chooses: guide and teacher
1. Name the tool and the exact place (page, tab, button) - from the owning skill, not from memory.
2. Exact settings: model, resolution, ratio, length, quality mode, references, every field he must fill.
3. Numbered steps, one action per step, each with the why in one sentence and what he should see on screen.
4. The prompt or text, ready to copy, in English, in a code block.
5. The check: how he knows it worked; the most likely failure and its one-change fix.
6. The cost line before any paid action: what, how many, how much, and wait for his explicit yes.
7. After it works: one line he can write in his notes (what was learned).
If a connected tool can do the step for him, say so and offer both routes in the card - doing it for him still needs his yes for anything paid.
