# התחל כאן - מדריך בעברית

נכתב ב-21 בנובמבר 2026. המדריך מסביר מה יש בתיקייה, איך שומרים אותה במחשב, ואיך מעלים את הסקילים לחשבון.

## חלק 1 - מה יש בתיקייה

1. המחקר: דוחות גולמיים, קובצי ידע, דוחות אימות.

```
advertising-knowledge/research-raw/
advertising-knowledge/knowledge/
advertising-knowledge/verification/
```

2. שמונה סקילים חדשים, כל אחד כקובץ מוכן להעלאה.

```
advertising-knowledge/ready-to-upload-skill-zips/
```

3. הטקסט של אותם סקילים לקריאה, ו-108 רשימות עריכה לסקילים הקיימים.

```
advertising-knowledge/skill-drafts/
```

4. מערכת הסטודיו לפרסום, שעובדת בתוך התוכנה במחשב.

```
advertising-studio/
.claude/
```

5. גיבוי של הסקילים השמורים שלך, כפי שהיו ב-20 בנובמבר 2026 (רק בקובץ שהורדת, לא באינטרנט).

```
my-saved-skills-backup-2026-11-20/
```

## חלק 2 - שמירה במחשב

1. הורד את קובץ הגיבוי מהשיחה.
2. העבר אותו לתיקיית המסמכים. למה: תיקיית ההורדות מתנקה בקלות.
3. לחץ עליו לחיצה ימנית ובחר לחלץ הכל.
4. התיקייה שנוצרה היא העותק שלך. היא לא תלויה בענן.

## חלק 3 - העלאת שמונת הסקילים החדשים

למה מעלים: סקיל נכנס לרשימת הסקילים של החשבון רק אחרי העלאה. קובץ במחשב לבדו לא מספיק.
המקור להוראות: דף התמיכה הרשמי, נקרא ב-21 בנובמבר 2026.

```
https://support.claude.com/en/articles/12512180
```

1. פתח את האפליקציה או את האתר.
2. היכנס למסך הסקילים. בדף הרשמי הוא נקרא:

```
Customize > Skills
```

3. אם אין לך "Customize", הדף הרשמי מזכיר גם את המסלול הזה:

```
Settings > Capabilities
```

4. לחץ על סימן הפלוס, ואז על יצירת סקיל.
5. בחר באפשרות:

```
Upload a skill
```

6. בחר קובץ אחד מהתיקייה של הקבצים המוכנים. התחל בזה:

```
creative-request-advisor-tools-models-prices-then-teach-steps.zip
```

7. אחרי ההעלאה, ודא שהסקיל מופיע ברשימה והמתג שלו דולק.
8. חזור על צעדים 4 עד 7 לשבעת הקבצים האחרים, בסדר הזה:

```
advertising-and-media-hub.zip
advertising-production-pipeline-brief-to-delivery.zip
advertising-tv-and-streaming-specs-israel-and-global.zip
advertising-social-media-specs-and-formats.zip
advertising-outdoor-radio-podcast-print-cinema-in-app-specs.zip
advertising-israel-broadcast-approvals-and-ad-law-basics.zip
advertising-client-process-quotes-contracts-rights.zip
```

9. בדיקה: פתח שיחה חדשה וכתוב "לקוח רוצה פרסומת של 30 שניות לטלוויזיה". אם הסקיל המרכזי נטען, ההעלאה הצליחה.

אם העלאה נכשלת, הדף הרשמי מונה שתי סיבות: הקובץ גדול מדי, או ששם התיקייה שבתוך הקובץ שונה משם הסקיל. הקבצים כאן נבדקו: בכל אחד יש תיקייה בשם הסקיל ובתוכה הקובץ הראשי.

## חלק 4 - הוספת הסעיף ל-108 הסקילים הקיימים

למה לא בהעלאה: לא ידוע מה קורה כשמעלים קובץ בשם של סקיל שכבר שמור. הדף הרשמי לא אומר אם הוא מוחלף, נדחה או מוכפל. לכן הדרך הבדוקה היא כרטיסי שמירה.

1. פתח שיחה רגילה חדשה (לא שיחת ענן של קוד).
2. צרף לשיחה את שני הקבצים האלה מהתיקייה:

```
advertising-knowledge/skill-drafts/ROUNDS-PLAN.md
advertising-knowledge/skill-drafts/general-rule-section.md
```

3. כתוב: "השתמש בסקיל פרסום הכרטיסים. הוסף את הסעיף שבקובץ לכל סקיל ברשימת הסבבים, שלושה סקילים בכל כרטיס, והוכח כל עריכה מול הסקיל השמור לפני הכרטיס."
4. לחץ שמירה על כל כרטיס. יש 36 סבבים של עריכות.
5. אחרי כל כמה סבבים, פתח סקיל אחד ובדוק שהסעיף "General rule" מופיע בו פעם אחת.
6. אל תלחץ שוב על כרטיס ישן אחרי ששיחה אחרת שינתה את אותו סקיל. זה עלול לבטל עבודה חדשה.

שמונה סקילים יעברו 18 ק"ב בגלל הסעיף. הרשימה שלהם כתובה בסוף קובץ הסבבים. ההחלטה אם לפצל אותם שלך.

## חלק 5 - עבודה עם מערכת הסטודיו מהמחשב

1. התקן את התוכנה במחשב אם אינה מותקנת.
2. פתח חלון פקודות בתוך התיקייה שחילצת.
3. הרץ:

```
claude --agent executive-producer
```

4. כתוב למפיק איפה חומרי הלקוח ומה המטרה.
5. המפיק עוצר בכל שער וממתין לאישור שלך. שום יצירה בתשלום לא רצה לפני "כן" מפורש.

## חלק 6 - מה נעשה באמת, ומה לא

נעשה:
1. 10 דוחות מחקר ו-3 דוחות השלמה.
2. 304 עובדות נקראו מחדש מול המקור בידי סוכני אימות נפרדים: 286 עברו, 4 עודכנו, 1 נכשלה ותוקנה.
3. 8 סקילים חדשים נכתבו ועברו בדיקת תקינות.
4. 108 רשימות עריכה נבנו והוכחו.
5. מערכת הסטודיו נבנתה. בדיקת המבנה ובדיקות השערים עברו. סוכן אחד מתוך שבעת המומחים נבדק בהרצה חיה.

לא נעשה או לא אומת:
1. כרטיסי השמירה עצמם.
2. הפרסומת לתיקיית "דיגיטלי": אין גישה למחשב מהשיחה בענן.
3. נתוני המס הישראליים לא נקראו בדף של רשות המסים. שני מקורות אחרים מסכימים עליהם. יש לבדוק מול רואה חשבון.
4. מפרטי המסירה של קשת, רשת, כאן, ערוץ 14, הוט ויס לא נמצאו.
5. עוצמת הקול לשידור בישראל: שלושה מקורות נותנים שלושה מספרים שונים.
6. מחירי אדובי פיירפליי נשענים על שני מדריכים חיצוניים בלבד.
7. יוטיוב חסם את הקריאה ב-21 בנובמבר. כמה סרטונים רשומים "לא נקרא".
8. במערכת הסטודיו לא נבדקו: האצלה מהמפיק עצמו, שישה מהמומחים, בקשות האישור, בחירת מודל חיה.
9. רבים מהמחירים שנקראו הם מבצעי סוף נובמבר. יש לבדוק מחדש לפני כל החלטה.

זה לא ייעוץ משפטי או ייעוץ מס. הקבצים מדווחים מה כתוב במקורות, עם חוזק המקור ליד כל שורה.
